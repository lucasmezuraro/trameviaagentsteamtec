# Cartão de trabalho

- ID / projeto / objetivo observável:
- Requisitos cobertos (FR-###) e a evidência que refutaria cada um:
- Repositório autorizado / commit-base completo / dependências integradas:
- Branch e checkout absolutos (confirmados pelo coordenador):
- Donos de contrato e versões / política e hash do plano:
- Especialista / sessão / run_id / tentativa:
- Escopo permitido de arquivos e recursos; exclusões explícitas:
- Ações permitidas / ambiente / conectores disponíveis:
- Fora do escopo:
- Aceite: exemplos positivos, negativos e evidência exigida:
- Testes (identificadores; comandos revisados separadamente):
- Limites: duração, tentativas, custo autorizado e critério de parada:
- Revisores e operador humano quando aplicável:
- Dúvidas bloqueantes:

Sem especificação não há cartão: os requisitos cobertos vêm de `templates/spec.md` e já
precisam estar sem dúvida aberta. Um cartão que não cobre requisito algum é lacuna, e o
validador o recusa.

Não colocar segredos nem dados reais. A especificação JSON do laboratório está em
examples/plan.json e src/policy.mjs. Este cartão adiciona contexto sem conceder permissões.
